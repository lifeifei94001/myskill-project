# 二手笔记本回收参数收集与格式化专家 (Laptop Specs Collector)

本技能专为**二手 3C 回收业务（类似爱回收、转转、找靓机）的机型排列组合与建档系统**打造。当需要录入新笔记本机型时，自动通过权威硬件库（中关村在线 ZOL、京东自营规格、品牌技术文档）交叉比对，将散落的硬件配置自动汇聚并标准化为**四维顿号分隔格式**，可直接一键复制粘贴至工作台。

## 二、 字段清洗与规范化铁律

在提取硬件参数时，严格遵循 `references/hardware_naming_standards.md`：

1. **发布时间 (Release Date)**：
   - 格式强制规范为 `YYYY/MM/DD`（如 `2024/01/17`）；若查不到具体日，填 `YYYY/MM`（如 `2024/01`）。
   - 以国行官方发布会或京东首发上市日期为准。
2. **处理器 CPU (Processor)**：
   - 剔除 `Intel`、`Core`、`AMD`、`Ryzen`、`酷睿`、`第14代` 等冗余修饰词；
   - 规范为行业通用的紧凑简称：`i9-14900HX`、`i7-14650HX`、`Ultra 7 155H`、`R7-7840H`、`M3 Pro`；
   - 多款 CPU 统一使用中文顿号（`、`）连接。
3. **显卡型号 (GPU)**：
   - 剔除 `NVIDIA`、`GeForce`、`Laptop GPU`、`移动版`、`独显` 等字样；
   - 规范为芯片核心型号：`RTX4060`、`RTX4070`、`RTX4080`、`RTX3060`；
   - 纯核显轻薄本（如无独显的 ThinkPad、集显轻薄本、MacBook）显卡统一填：`集显`；
   - 多款显卡统一使用中文顿号（`、`）连接。
4. **固态硬盘 (SSD)**：
   - 统一大写容量后缀 `G` 或 `TB`：`256G、512G、1TB、2TB`；
   - 严禁写 `512GB`、`1024G` 或 `1000G`。
5. **机械硬盘 (HDD)**：
   - **2020 年及以后机型**：绝大多数已全面普及全 M.2 NVMe，机械硬盘 100% 填 `无`；
   - **2016-2019 年老款游戏本**（如拯救者 R720、Y7000 2018 款）：若有 2.5 寸 SATA 盘位，填 `无、1TB` 或 `无、1TB、2TB`。

## 三、 4 步执行工作流

```
① 解析机型意图 ➔ ② 联网多源检索 ➔ ③ 参数聚合与去重 ➔ ④ 格式化出具复制卡
```

### 步骤 1：解析机型意图与年代
- 当用户输入机型名称（如 `拯救者Y9000P 2024`、`天选5 Pro`、`ThinkPad T14`、`MacBook Air M2`）时：
- 识别年份/代数：若用户未指定年份且该系列跨越多代，主动向用户确认具体年份（如 2023款 vs 2024款）或以最新款为默认推荐；
- 识别芯片阵营：若该机型同时存在 Intel 酷睿版与 AMD 锐龙版（如天选系列），明确注明是酷睿版、锐龙版还是两者合并。

### 步骤 2：联网检索权威信源
依据 `references/trusted_data_sources.md`，执行网络搜索：
- 首选检索策略：`中关村在线 笔记本参数 [机型全称]`
- 次选检索策略：`京东 自营 规格参数 [机型全称]`
- 辅助检索策略：联想 PSREF、华硕/戴尔官方产品规格书

### 步骤 3：参数清洗与排列组合预检
可调用内置清洗脚本 `scripts/format_specs.py` 进行数据验证：
```bash
python scripts/format_specs.py
```
确保每个字段的重复值被过滤，顿号无遗漏，且计算出理论 SKU 数量供用户核验。

### 步骤 4：出具结果与后续联动
1. 输出带分隔框的高亮代码块，方便用户一键复制；
2. 若用户提供了多个机型（批量模式），同时提供 Markdown 汇总对比表格；
3. 提示用户：“是否需要调整某个特定版本（如锐龙版/核显版），或直接开始下一个机型？”
