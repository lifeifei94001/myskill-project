# 笔记本配置组合查找与规格专家 (Laptop Specs & Real SKU Collector)

针对“单一笔记本机型与特定版本”，查找并核验其官方在售的全部真实配置组合（CPU × 运存 × 显卡 × 固态硬盘 × 机械硬盘）及上市时间，产出可直接用于后台机型录入与审计的标准化 Markdown 表格，并支持从真实 SKU 逆向生成后台快速录入字典卡。

---

## 一、 何时使用

- 用户给出笔记本机型名称，要求查找该机型都有哪些官方在售配置版本；
- 需要核对某机型的 CPU / 运存 / 显卡 / 固态硬盘 / 机械硬盘 组合是否真实录全；
- 需要确认某机型的上市时间（发布日期、首销日期）；
- 后台新增笔记本机型或二手 3C 回收建档前的配置真实性校验。

---

## 二、 核心原则（真实性第一铁律）

1. **组合真实存在且精准（零幻觉）**：
   - 必须保证表格中列出的**每一个配置组合均为官方真实发售的独立 SKU**；
   - **绝对严禁**自行将 CPU、内存、硬盘规格进行笛卡尔积自由组合，**绝对严禁**凭空编造、猜测或推测不存在的参数组合。不确定的一律不瞎猜，一律不新增未经证实的参数。
2. **版本精准隔离与默认标准版规则（强约束）**：
   - **未指定版本**：若用户发出的机型名称未标注具体子版本/衍生后缀（如仅输入“荣耀 笔记本 X16 2026”），**默认仅收录“标准版（酷睿标准版/标配版）”**，绝对禁止将战斗版、锐龙版、Plus 版等其他衍生机型混入表格中；
   - **指定版本**：若用户明确标注了具体子版本（如“荣耀 笔记本 X16 2026 战斗版”），**则仅收录该特定衍生版本**自身的真实 SKU，绝对禁止混入标准版或其他版本；
   - **严格限定年份**：若用户指定了特定年份（如“2025款”），必须严格仅收录该特定年份的真实 SKU，绝对禁止混入前代或后代产品（如严禁将 2025 款 IAX10H 混入 2026 款）。
3. **上市时间严格精确到年月日**：
   - 上市时间（发布日期、首销日期）必须精确到 **YYYY年MM月DD日**（如“2026年04月23日”），严禁仅填写年份或年月（如不得写“2026年04月”）；
   - “发布日期”即为官方正式公布并开启预售/开售的具体日期；
   - “首销日期”为结束预售全面开售的具体日期（发布即开售时注明“发布即首销”）。
4. **以官方配置选择页为准**：
   - 优先参考品牌官网配置页、官方发布会通稿及京东/天猫官方旗舰店在售 SKU 列表，禁止根据爆料或未经核实的评论反推组合。
5. **一个配置组合 = 一行**：
   - CPU、运存、显卡、固态硬盘、机械硬盘五项中任意一项不同，即视为不同配置，必须拆分为独立行。
6. **仅使用可信来源**：
   - 品牌官网配置页/通稿 → 官方旗舰店真实在售 SKU → 中关村在线（ZOL）/太平洋电脑网参数页。严禁论坛、贴吧、自媒体爆料。
7. **同版本追加批次专项检索**：
   - 仅在该指定版本（如标准版自身）首发后追加的同型号新规格时执行专项检索，严禁将“战斗版”或“锐龙版”等独立衍生机型当成“追加批次”混入标准版表格中。

## 三、 工作流程

```
① 确认机型版本边界 ➔ ② 权威信源严格检索 ➔ ③ 逐一提取官方真实在售 SKU ➔ ④ 同版本追加批次检视 ➔ ⑤ 上市时间年月日校验 ➔ ⑥ 双层结构化输出
```

1. **确认机型的官方完整名称与版本定位**：
   - 检查用户是否提供了版本后缀。若未提供，**默认按标准版检索**，不主动合并战斗版、锐龙版等衍生机型；
   - 若明确提供了版本后缀，则**仅针对该特定版本进行检索**。
2. **按数据来源优先级检索**：
   - 第一优先级：品牌官网配置选择页/购买页、官方发布会通稿；
   - 第二优先级：京东/天猫官方旗舰店真实在售 SKU 列表；
   - 第三优先级：中关村在线（ZOL）/太平洋电脑网参数页核验详细型号。
3. **逐一列出官网/官方店铺中在售的每个真实 SKU**：
   - 严格按八大固定字段填写（CPU、运存、显卡、固态硬盘、机械硬盘、屏幕尺寸、是否已下架、来源）。
4. **执行同版本“追加批次专项检索”**：
   - 检索该具体版本首发后是否有新增配置（严禁跨版本混入）。
5. **检索开售/发布日期与首销日期（严格精确到 YYYY年MM月DD日）**。
6. **校验去重与真实性复核**：
   - 同一机型版本下不得出现完全重复的行；确保每一行组合均有明确的出处证据；确认未混入其他衍生版本。
7. **出具输出**：
   - 主输出：固定字段 Markdown 表格 + 上市时间说明；
   - 附带输出（兼容工作台）：基于表格中验证过的真实 SKU，逆向去重提取后台录入卡片（顿号分隔，明确标注真实发售组合数，严禁写虚假笛卡尔积）。

## 四、 输出要求与字段定义

### 1. 核心在售组合表格（顺序固定，不得增删）

| 序号 | 字段名 | 填写规范 |
|:---:|:---|:---|
| 1 | **CPU** | 官方完整处理器型号（如 `Intel Core Ultra 9 285H`、`i7-14650HX`），不得简写或猜测代数 |
| 2 | **运存（内存）** | 容量+类型，如 `32GB LPDDR5X`、`16GB DDR5 5600MHz`；无法确认类型时仅填容量（如 `16GB`），容量必填、类型允许缺省 |
| 3 | **显卡** | 完整显卡型号（如 `NVIDIA GeForce RTX 5060 8GB`）；若全系核显统一填 `核芯显卡` 或 `集成显卡` |
| 4 | **固态硬盘（SSD）** | 容量（如 `1TB`、`512GB`）；同一 SKU 自定义多容量的拆分为独立行；不支持/无固态硬盘填 `空` |
| 5 | **机械硬盘（HDD）** | 容量（如 `1TB`）；机型不支持机械硬盘扩展位的填 `空`，不得填“无”等占位符 |
| 6 | **屏幕尺寸** | 仅当机型存在多尺寸版本时填写（如 `14英寸`、`16英寸`）；单一尺寸机型填 `空` |
| 7 | **是否已下架** | `是` / `否` |
| 8 | **来源** | 该行信息的来源渠道，如 `品牌官网` / `京东自营旗舰店` / `中关村在线` |

### 2. 上市时间说明（表格后单独输出，不并入配置表格）

| 字段名 | 填写规范 |
|:---|:---|
| **批次** | 若同一版本机型分多批次上市（首发批、同版本追加批等），每个批次单独一行说明；单一批次填 `空` |
| **发布日期** | 官方发布会/官网公布价格并开启预售或具体开售的日期，**必须精确到年月日（如“2026年04月23日”）**；无法确认填 `空` |
| **首销日期** | 结束预售、正式全面开售的具体日期，**必须精确到年月日（如“2026年04月23日”）**；发布即开售填写同年月日或注明 `发布即首销` |
| **版本差异说明** | 若同版本内不同配置档或不同批次上市时间不同，需逐一列出；无差异填 `空` |

### 3. 通用填写规范与禁令
- **空值占位**：全表统一使用 `空` 表示无法确认，**禁止**使用“无”、“/”、“-”、“—”等其他占位符；
- **真实性禁令**：表格内与表格外**绝对严禁**出现“可能”、“预计”、“疑似”、“大概”等不确定性措辞；
- **容量单位**：与官方标注一致（GB / TB），不做混淆换算；
- **日期格式**：必须使用 `YYYY年MM月DD日` 格式，严格精确到具体日，**不得仅写到月份**。

## 六、 常用机型对照与典型反例警示

- ❌ **严重反例 1（虚假笛卡尔积）**：某机型官方只卖“i7 + 4060”和“i9 + 4070”两款，严禁通过 2×2 笛卡尔积捏造出“i7 + 4070”或“i9 + 4060”。
- ❌ **严重反例 2（跨版本串味）**：严禁把荣耀 X16 的“战斗版”或“锐龙版”混进“标准版”中；严禁把 2025 款（IAX10H，配 Ultra 9 275HX）混入 2026 款中。
- ✅ **正确示范**：问哪个特定版本，就仅针对该版本的官方售卖页面，一行一行列出真实独立 SKU，不确定的参数坚决不猜。
