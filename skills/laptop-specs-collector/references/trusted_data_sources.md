# 笔记本参数可信信源与检索技巧 (Trusted Data Sources)

为二手回收平台检索笔记本硬件参数时，为了防止漏掉低配或定制版 SKU，需结合以下信源交叉比对：

---

## 1. 核心权威信源矩阵

| 推荐评级 | 信源名称 | 适用机型与优势 | 网址 / 搜索技巧 |
|:---:|---|---|---|
| ⭐⭐⭐⭐⭐ | **中关村在线 (ZOL)** | 国内最全笔记本参数库，配置列表清晰罗列了同系列下所有在售细分型号 | `site:detail.zol.com.cn [品牌 机型] 参数` |
| ⭐⭐⭐⭐⭐ | **京东自营规格参数页** | 上市时间准确，官方发售版 SKU 覆盖全，不易遗漏大促特供版 | `[品牌 机型] site:item.jd.com 包装与参数` |
| ⭐⭐⭐⭐ | **官方支持中心 / 规格书** | 联想 PSREF (规格书)、华硕 ROG 官网、Apple 官网技术规格 | 联想 `psref.lenovo.com`，苹果 `apple.com.cn/macbook-pro/specs/` |
| ⭐⭐⭐⭐ | **太平洋电脑网 (PConline)** | 老旧机型（2015-2020 年）参数极为详尽，查机械硬盘必用 | `site:product.pconline.com.cn [机型]` |
| ⭐⭐⭐ | **快科技 / 极客湾 / 笔吧评测室** | 首发新品上市时间、首发首批配置梳理 | 查新品发布会具体年月日 |

---

## 2. 检索关键词模板

### 针对游戏本（多 CPU、多 GPU 组合）
```
"联想 拯救者 Y9000P 2024" (上市时间 OR 发布时间 OR 参数 OR 配置表)
"华硕 天选5 Pro" (i7 OR i9 OR 4060 OR 4070) 参数 中关村在线
```

### 针对轻薄本（重点在 CPU 与内存/固态配置）
```
"ThinkPad X1 Carbon 2023" 参数 详细配置
"MacBook Air M2 13寸" 规格表 发布时间
```

---

## 3. 常见陷阱与避坑准则

1. **同模具多代混淆**：
   - 比如“拯救者 Y9000P”有 2021款、2022款、2023款、2024款、2025款。检索时必须严格限定年份或核心代数（如 13代、14代）。
2. **酷睿版与锐龙版区分**：
   - 常见机型分 Intel 版与 AMD 版（如天选5 Pro 酷睿版 vs 锐龙版），两者的 CPU 列表完全不同，必须确认用户是要某一个版本还是全系列合并。
3. **机械硬盘存疑时**：
   - 若机型上市时间在 2020 年以后且厚度小于 25mm，机械硬盘直接填 `无`。
   - 若机型属于旧款模具且带有 2.5 寸 SATA 盘位，机械硬盘填 `无、1TB` 或 `无、1TB、2TB`。
