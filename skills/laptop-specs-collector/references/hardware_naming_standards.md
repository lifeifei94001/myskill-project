# 二手笔记本回收行业硬件参数规范化字典 (Hardware Naming Standards)

在二手 3C 回收业务（爱回收、转转、找靓机等）中，为了确保下游能够精准排列组合出真实可收购的 SKU 并与报价字典无缝匹配，硬件参数必须遵循严格的**精简别名与顿号分隔规范**。

---

## 1. 核心五维字段规范

| 字段名称 | 推荐输入格式 | 分隔符 | 典型示例与说明 |
|---|---|---|---|
| **发布时间** | `YYYY/MM/DD` 或 `YYYY/MM` | 无 | 如 `2024/01/17` 或 `2023/04`（国内以品牌官方发布会或京东首发时间为准） |
| **处理器 CPU** | 官方规范简称 | 顿号 `、` | 如 `i9-14900HX、i7-14650HX` 或 `R7-7840H、R9-7940HX` |
| **显卡型号** | 规范芯片型号 | 顿号 `、` | 如 `RTX4060、RTX4070`，轻薄本核显统一填 `集显` 或 `核显` |
| **固态硬盘** | 容量简称（大写G/TB） | 顿号 `、` | 如 `512G、1TB、2TB`（严禁写 `512GB` 或 `1024G`） |
| **机械硬盘** | 容量或 `无` | 顿号 `、` | 2020 年及以后笔记本绝大多数为 `无`；老款游戏本为 `无、1TB、2TB` |

---

## 2. CPU 常见规范写法表

### Intel 酷睿与酷睿 Ultra
- **14代 / 13代 HX 系列**：`i9-14900HX`、`i7-14700HX`、`i7-14650HX`、`i5-14500HX`、`i9-13900HX`、`i7-13700HX`、`i5-13500HX`
- **标压 H / 性能轻薄**：`i9-13900H`、`i7-13700H`、`i5-13500H`、`i7-12700H`、`i5-12500H`
- **酷睿 Ultra 架构**：`Ultra 9 185H`、`Ultra 7 155H`、`Ultra 5 125H`
- **低压 U 系列**：`i7-1355U`、`i5-1335U`、`i7-1255U`

### AMD 锐龙 Ryzen
- **8000 / 7000 系列**：`R9-7945HX`、`R9-7940HX`、`R9-7940H`、`R7-8845H`、`R7-7840H`、`R7-7840HS`、`R5-7640HS`、`R5-7535H`
- **6000 / 5000 系列**：`R7-6800H`、`R5-6600H`、`R7-5800H`、`R5-5600H`

### Apple 苹果 M 系列
- **MacBook Pro / Air**：`M3 Max`、`M3 Pro`、`M3`、`M2 Max`、`M2 Pro`、`M2`、`M1 Max`、`M1 Pro`、`M1`（可带核数如 `M3 Pro 11核`、`M3 Pro 12核`）

## 3. 显卡 GPU 常见规范写法表

### NVIDIA GeForce RTX / GTX
- **40 系列**：`RTX4090`、`RTX4080`、`RTX4070`、`RTX4060`、`RTX4050`
- **30 系列**：`RTX3080Ti`、`RTX3080`、`RTX3070Ti`、`RTX3070`、`RTX3060`、`RTX3050Ti`、`RTX3050`
- **20 / 16 系列**：`RTX2060`、`GTX1660Ti`、`GTX1650`
- **轻薄本独显**：`MX550`、`MX450`、`MX350`
- **非独显机型**：统一写为 `集显`（或平台惯用的 `核显`）

---

## 4. 硬盘容量规范

- **固态容量排序**：通常从小到大或从大到小排列，统一单位为 `G` 与 `TB`：
  - 轻薄本常见：`512G、1TB` 或 `256G、512G、1TB`
  - 游戏本常见：`512G、1TB、2TB`
- **机械硬盘判断规则**：
  - 2020 年及以后生产的轻薄本、全能本、主流游戏本（M.2 NVMe 双盘位普及）：机械硬盘 100% 填 `无`；
  - 2016-2019 年生产的老款游戏本（如联想拯救者 R720/Y7000 2018款、戴尔游匣G3/G7）：多为 `无、1TB、2TB`。
